Панель управления Ецци:
h - Печать панели управления

Переброс костей осуществляется вводом их значений:
    Пользователь вводит значения костей, которые хочет ОСТАВИТЬ
    Пример:
        output: [5, 4, 3, 2, 5]
        input: 55
        output: [5, 5, n, n, n]

Режим записи результа:
    В режим записи программа автоматически перейдет после второго переброса костей
    Или
    s - (save) - принужденный переход в режим записи

    Команды в режиме записи:
    1 - 6: запись в соответствующее число
    q: Пара
    w: Две Пары 
    e: Сет 
    r: Каре
    t: Фулл Хаус
    y: Малый Стрит
    u: Большой Стрт
    i: Ецци
    o: Шанс

    Так же есть функция быстрой записи, (s + n):
    s1, s2, s3, s4, s5, s6;
    sq, sw, se, sr, st, sy, su, si, so
    

    Один (1, один, Один)
    Два (2, два)
    Три (3, три)
    Четыре (4, четыре)
    Пять (5, пять)
    Шесть (6, шесть)
    Пара (пара, п)
    Две Пары (две пары, пп)
    Сет (сет, с)
    Каре (каре, к)
    Фулл Хаус (фуллхаус, фх, ф)
    Малый Стрит (малый стрит, мс, м)
    Большой Стрит (большой стрит, бс, б)
    Ецци (ецци, е)
    Шанс (шанс, ш)
